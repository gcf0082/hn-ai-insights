## 🔍 深度分析（1 篇）

### 1. [Show HN: Mcp2cli – 每个 API 一个 CLI, 比原生 MCP 少 96-99% token](https://news.ycombinator.com/item?id=47305149)

**英文标题:** Show HN: Mcp2cli – One CLI for every API, 96-99% fewer tokens than native MCP

**分数:** 79 | **评论:** 45 | **来源:** [GitHub](https://github.com/knowsuchagency/mcp2cli)

#### 核心内容
- MCP 服务器每次对话都注入完整工具 schema，30 个工具每轮消耗约 3600 token
- mcp2cli 在运行时将任何 MCP 服务器或 OpenAPI 规范转换为 CLI，按需发现工具
- 无需代码生成，服务器变更无需重建，适用于任何 LLM（只需 shell 调用 CLI）
- token 节省实测：30 工具 15 轮节省 96%，120 工具 25 轮节省 99%
- 可作为 AI 编码代理（Claude Code、Cursor、Codex）的可安装技能使用

#### 关键讨论
- 社区认可 token 优化价值，尤其是多工具场景下的成本问题
- 与 Anthropic 的 Tool Search 对比：mcp2cli 更通用（适用于任何 LLM），发现成本更低（~16 token/工具 vs ~121）
- 支持 OpenAPI 规范和 MCP 服务器，统一两种 API 交互方式
- 缓存机制：规范缓存 1 小时 TTL，可自定义

#### 分析价值
⭐⭐⭐⭐ 提供了 MCP 工具调用的创新优化方案，通过 CLI 抽象层实现 96-99% 的 token 节省，对多工具 AI 代理开发有重要参考价值
